WHAT THE VIDEO SKIPPED
• I counted 3,026 icons in the repo today: 957 objects, plus versions with a badge (a plus, a check, a lock) and "off" versions.
• Every icon moves the way the real thing moves, in 460 milliseconds. A folder opens. An envelope unseals. A lock pops.
• The self-check takes pictures of each icon at rest, on hover, in between, at 24 and 28 pixels and in all 7 color sets. Then it writes a list of what broke a rule.
• New icons start from the closest of 66 worked examples, so Claude never starts from zero.
